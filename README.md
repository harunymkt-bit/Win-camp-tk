# Casino Games Hosting Platform

A comprehensive casino games hosting platform for developing, managing, and distributing casino games.

## Features
- Game management system
- Player account management
- Wallet and betting system
- Game APIs for third-party integration
- Admin dashboard
- RNG (Random Number Generator) system
- Transaction logging

## Supported Games
- Slots
- Table Games (Blackjack, Roulette, Baccarat)
- Live Games
- Other games

## Tech Stack
- Backend: Node.js with Express
- Frontend: React
- Database: PostgreSQL
- Authentication: JWT
